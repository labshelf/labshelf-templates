# LabShelf Templates

The LabShelf Community catalog: LaTeX and Typst project templates that anyone can use and publish from LabShelf.

## Use a template

Open the Projects tab in LabShelf and choose Templates. The gallery lists this catalog, Typst Universe and your own templates. Pick one to start a new project from its files.

## Publish a template

In LabShelf, open a project and choose Publish template. Sign in with GitHub, then Submit for review. LabShelf opens the pull request for you. People without LabShelf can follow [CONTRIBUTING.md](CONTRIBUTING.md).

## Review rules

A pull request passes when:

- `template.yaml` is valid and its `id` equals the folder name;
- `license` is an SPDX identifier that allows redistribution and modification (see [LICENSES.md](LICENSES.md));
- every path stays inside the template: no `..`, no backslash, no absolute path, no symbolic link;
- no file or folder is named `latexmkrc` or `.latexmkrc`, and the template never enables shell-escape;
- `preview/thumbnail.png` and `preview/sample.pdf` exist and were compiled by the publisher with the declared engine; the catalog never compiles;
- sizes stay within the limits: thumbnail 400 to 1600 px wide and at most 512 KiB, sample at most 10 MiB, at most 500 files, 5 MiB per file and 20 MiB per template.

## Layout

```
templates/<id>/
  template.yaml    manifest
  files/           the project files, copied as they are
  preview/         thumbnail.png and sample.pdf
index.json         generated by CI, never edited by hand
validate.mjs       the validator CI runs on every pull request
build-index.mjs    builds index.json on main
```
